# 盯盘模块 — 需求规格说明书

> 版本: v0.1-draft | 日期: 2026-06-17 | 状态: 待确认

---

## 1. 背景

已有 `broker/monitor.py` 大单监控模块（检测单笔大资金进出），但缺少一个综合盯盘面板——同时看涨跌停、异动拉升、板块热点、自选股状态。

**与大单监控的关系：**
- 大单监控 = 发现"大资金动作"
- 盯盘模块 = 发现"市场整体动向"
- 两者共用 `TDXQuotesPoller` 数据轮询，互补不冲突

---

## 2. 核心功能

### 2.1 涨跌停监控

**触发条件：** 股票涨跌幅接近 ±9.9%（主板）/ ±19.9%（科创/创业板）

**输出信息：**

| 字段 | 说明 |
|------|------|
| 股票代码/名称 | — |
| 涨跌幅 | 当前涨跌幅 % |
| 封板时间 | 最早触及涨停的时间 |
| 封单量 | 买1挂单量（涨停）/ 卖1挂单量（跌停） |
| 封单金额 | 封单量 × 价格 |
| 换手率 | 当前换手率，判断是合力还是出货 |
| 是否炸板 | 涨停后是否开板过 |
| 连板数 | 连续涨停天数 |

**告警分级：**

| 级别 | 条件 |
|------|------|
| ⭐ 涨停 | 触及涨停，封单金额 > 5000万 |
| ⭐⭐ 强封 | 封单金额 > 2亿，换手率 < 5% |
| ⭐ 跌停 | 触及跌停，封单金额 > 3000万 |
| ⭐⭐ 打压 | 封单金额 > 1亿，换手率 > 10% |

### 2.2 异动拉升监控

**触发条件：**

| 类型 | 条件 |
|------|------|
| 快速拉升 | 1分钟内涨幅 > 1.5% |
| 放量拉升 | 1分钟内涨幅 > 1% AND 成交量 > 日均量的 20% |
| 快速跳水 | 1分钟内跌幅 > 1.5% |
| 尾盘偷袭 | 14:50后 5分钟内涨幅 > 2% |

**输出信息：** 股票、涨跌幅、拉升量能、触发时间、现价、五档盘口

### 2.3 板块热点

**数据来源：** TDX 板块数据 + 实时行情

**输出信息：**

| 维度 | 说明 |
|------|------|
| 涨幅榜 | 行业/概念板块涨幅排名 Top10 |
| 资金流 | 板块内股票主动买盘 - 主动卖盘合计 |
| 领涨股 | 每个板块涨幅最大的成分股 |
| 涨停数 | 板块内涨停股票数量 |

### 2.4 主力资金流监测

**数据来源：** TDX 实时行情中的 `active_buy`（外盘/主动买）和 `active_sell`（内盘/主动卖）

**原理：** 每隔 3 秒对比前后快照，计算区间内的主动买增量 - 主动卖增量，得到净资金流。

**触发条件：**

| 类型 | 条件 |
|------|------|
| 主力大幅流入 | 1分钟内净流入 > 5000万 |
| 主力大幅流出 | 1分钟内净流出 > 5000万 |
| 持续流入 | 连续 3 分钟内每分钟净流入 > 2000万 |
| 持续流出 | 连续 3 分钟内每分钟净流出 > 2000万 |

**输出信息：** 股票、净流入/流出金额、时间窗口、内外盘比例

### 2.5 自选股状态

**数据来源：** 实盘股票池（62只）

**实时刷新：**

| 字段 | 刷新频率 |
|------|----------|
| 现价 / 涨跌幅 | 3秒 |
| 5档盘口（买1/卖1） | 3秒 |
| 成交额 / 换手率 | 3秒 |
| 日内最高/最低 | 3秒 |
| 相对昨收 | 3秒 |

**排序/筛选：** 按涨跌幅排序，红涨绿跌，一眼看清持仓/关注股票

## 3. 技术架构

```
TDXQuotesPoller (共享)
    │
    ├── Detector → 大单告警 (已实现)
    │
    └── MarketWatcher (新增)
         ├── LimitUpDownWatcher   → 涨跌停
         ├── SurgeWatcher         → 异动拉升
         ├── SectorHeatmap        → 板块热点
         └── PoolStatusTracker    → 自选股状态
              │
              └── SSE → live.html 盯盘面板
              └── JSON → live_trading.log
```

## 9. 架构调整

全市场涨跌停需要单独扫描，不能只用自选股池的 poller。方案：

```
MarketWatcher
├── TDXQuotesPoller (共享, 自选股 62只)
│   ├── PoolStatusTracker   → 自选股状态
│   └── SurgeWatcher         → 异动拉升
│
├── TDX 板块API (直接调用)
│   └── SectorHeatmap        → 板块涨幅榜
│
└── TDX 全市场扫描 (涨跌停专用)
    └── LimitUpDownWatcher   → 涨跌幅 ≥ 9.5% 的股票
```

涨跌停全市场扫描不逐只轮询（5000+ 只太慢），改为：
- 利用 TDX 的 `get_security_quotes` 分批获取（每批 50 只，约 1.5 秒一批）
- 只过滤 `pct_chg >= 9.5` 的，全市场扫描约 30 秒完成一轮
- 或者用更快的方案：只扫收盘涨停/跌停信号
